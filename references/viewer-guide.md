# 网页使用说明（交付时讲给用户听）

## 开场
- 首页是一团漂浮的照片星云，日期翻牌显示今天。把带纸飞机的圆钮向右滑到底（或直接点它 / 按回车）：照片被吸进中心 → 穿越 → 日期倒流到最早一段回忆 → 照片在你身边爆散开。
- 启动时开始播放背景音乐（随机一首，约 8 秒渐入）。

## 三种模式（顶部切换）
| 模式 | 是什么 | 怎么操作 |
|---|---|---|
| 全景 | 站在照片球中心，所有照片环绕四周 | 拖动环顾；滚轮/捏合往外拉，退到球外看整颗球；左侧选年份会转过去并高亮那一年 |
| 近景 | 照片球像削苹果皮一样拉成 3D 螺旋塔，一段回忆一张 | 滚轮/拖动/方向键沿螺旋翻看；捏合或右侧滑杆让塔靠近/后退（缩到最远看到整座塔）；左侧年份直接跳转 |
| 解答之书 | 一本皮面的书 | 写下问题（或心里默念）→ 点书或右侧羽毛笔翻开（带翻书声），书页翻动，停在一张回忆照片和一句答案上 |

- 任何照片点一下就放大，背面是那天的文字、日期、地点和来源；可以前后翻。
- 切换全景/近景时人站着不动，是照片在动（削皮 / 卷回）。

## 其他
- 右上角：首页（回到开场）、☀ 回忆 / ☾ 夜色（亮色是柔和彩色的电影感，暗色是星空）。
- 左上角播放器：播放/暂停、下一首、＋（临时加本地音乐）。
- 网页需要联网加载 3D 引擎和字体（three.js、gsap、Google Fonts），照片和音乐都在本机。
